# Context Menu Hider для Firefox (исходный код)

Программа скрывает пункты контекстных меню Firefox, Floorp, LibreWolf, Waterfox и Zen. Отмеченные пункты записываются в `userChrome.css` выбранного профиля.

Готовый exe лежит в папке [`../bin`](../bin). Python для него не нужен.

## Возможности

- Пункты меню читаются прямо из `omni.ja` установленного браузера и подписываются по-русски.
- Разделы по действиям (ссылки, изображения, медиа, выделение текста, поля ввода, вкладки и другие) и по меню браузера (боковая панель, закладки, панели инструментов, загрузки и другие).
- «Все пункты» с поиском, «Выбранные», «Новое» (пункты, которые появились после обновления браузера), «Нет в этой версии».
- Расширения берутся из `extensions.json` профиля. Одна галочка скрывает все пункты расширения, в том числе созданные динамически.
- «Свои ID»: собственные ID и CSS-селекторы.
- «Предпросмотр меню»: меню выглядит так, как в браузере. Щелчок скрывает пункт, перетаскивание меняет порядок пунктов и разделителей (через CSS `order`).
- Перед записью создаётся резервная копия `userChrome.css.bak-…` (хранятся последние 10). Секция программы между маркерами заменяется целиком, остальной CSS не трогается.
- Проверка и автоисправление незакрытых скобок в CSS.
- Тёмная и светлая темы, сохранение профиля и настроек в `%APPDATA%\ContextMenuHider`.
- Горячие клавиши: Ctrl+F поиск, Ctrl+S применить, F5 пересканировать, Ctrl+Tab и Ctrl+1…9 переход по разделам, Esc очистить поиск.

## Важно

Firefox читает `userChrome.css` только если в `about:config` параметр `toolkit.legacyUserProfileCustomizations.stylesheets` равен `true`. После изменения меню браузер нужно полностью перезапустить.

## Запуск из исходников

Нужен Python 3.9 или новее с tkinter (обычный установщик с python.org подходит). Сторонних библиотек нет.

```bat
python firefox_context_menu_hider.py
```

## Сборка exe

На Windows запустите `build.bat` из этой папки. Он установит PyInstaller и соберёт `dist\FirefoxContextMenuHider.exe`.

Вручную то же самое:

```bat
python -m pip install --upgrade pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name FirefoxContextMenuHider --icon icon.ico --version-file version_info.txt ^
  --exclude-module unittest --exclude-module pydoc --exclude-module test ^
  firefox_context_menu_hider.py
```

Файлы в папке:

- `firefox_context_menu_hider.py`: вся программа;
- `icon.ico`: иконка exe;
- `version_info.txt`: сведения о версии в свойствах exe;
- `build.bat`: сборка exe.

Exe в `../bin` собран PyInstaller 6.22 на Python 3.12.10 (64-бит).

## Изменения в 4.6.0

- Новый раздел «Предпросмотр меню». Меню нарисовано так, как его показывает браузер: в том же порядке, с названиями на языке браузера, значками, разделителями, подменю (стрелка «›») и подчёркнутой буквой быстрого выбора. Можно открыть меню вкладки, меню страницы, меню панели инструментов, закладок, загрузок, боковой панели и другие.
- Для меню страницы можно выбрать, по чему щёлкнули: страница, ссылка, изображение, выделение, поле ввода, медиа, фрейм, PDF. Набор пунктов примерный: браузер сам решает, что показать в каждом случае.
- Щелчок по пункту скрывает его или возвращает. Скрытые пункты зачёркнуты. Флажок «Как будет в браузере» убирает их совсем, чтобы увидеть итоговое меню.
- Пункты, которые браузер показывает только в особых случаях (несколько выбранных вкладок, группы, полноэкранный режим), спрятаны. Показать их можно флажком «Показать пункты «по ситуации»».
- Пункты и разделители можно перетаскивать мышью внутри меню и подменю. Ещё есть кнопки «Выше ↑» и «Ниже ↓» и клавиши: ↑/↓ — выбрать, Alt+↑/↓ — переместить, Пробел — скрыть, →/Enter — открыть подменю, ← — назад. У каждого меню есть «Сбросить порядок».
- Разделители можно скрывать по одному, в том числе те, у которых нет id. Для них программа строит селектор по соседнему пункту, например `#toolbar-context-menu > #toolbar-context-customize + menuseparator`. Если у соседей тоже нет id, используется `menuseparator:nth-of-type(N)`.
- Порядок записывается в ту же секцию `userChrome.css`, отдельным блоком между `/* ORDER BEGIN … */` и `/* ORDER END */`. Для каждого изменённого меню пишется `#меню > * { order: 1000 !important; }` и по строке `order: N` на каждый пункт. Блок пишется только для меню, где порядок менялся. При запуске он читается обратно, резервная копия CSS делается как раньше.
- Порядок меню вкладки берётся из раскладки самого браузера (`MENU_SECTIONS` в `tab-context-menu.js`), с учётом настройки `browser.tabs.contextmenu.altstructure.enabled`. Для остальных меню используется порядок из разметки.

Ограничения порядка:

- Порядок меняется только визуально, через CSS `order`. Стрелки клавиатуры в меню и автоматическое скрытие лишних разделителей браузер по-прежнему делает по исходному порядку.
- Пункты расширений и новые пункты, которых программа не знает, всегда оказываются в конце меню.
- Пункты, которые браузер добавляет из кода (Floorp, «Поделиться»), стоят в предпросмотре примерно там, где их вставляет браузер.
- Селекторы для разделителей без id привязаны к соседнему пункту. Если в новой версии браузера разметка поменяется, такой разделитель может перестать находиться.

## Изменения в 4.5.2

- Названия пунктов теперь берутся из самого браузера, на его языке: из `omni.ja` и из языкового пакета в профиле (`extensions/langpack-ru@….xpi`). Язык определяется по `intl.locale.requested`, а если он не задан, по языку сборки. Названия совпадают с тем, что видно в меню, например «Новая вкладка справа», «Добавить вкладку в новую группу», «Отключить звук вкладки».
- Буквы для быстрого выбора, которые браузер показывает в скобках, например «(Ц)», в название не входят. Они показаны во второй строке как «клавиша Ц». Там же видны другой вариант подписи (например «также: Отправить на мобильный») и встроенный перевод, если браузер показывает строку по-английски.
- Поиск находит пункт по названию из браузера, по встроенному переводу, по английскому названию и по id.
- Подписи, которые браузер задаёт из кода, теперь читаются правильно: «Отключить звук вкладки», «Добавить разделение экрана», «Спросить ChatGPT» (берётся выбранный чат-бот из `browser.ml.chat.provider`).
- В меню вкладки появился пункт «Поделиться». У него нет id, поэтому он скрывается по селектору `#tabContextMenu > menu.share-tab-url-item`.
- Разбор файлов локализации Fluent переписан: поддерживаются многострочные строки, варианты для числа вкладок и названия бренда.

## Изменения в 4.5.1

- Обычный Firefox теперь находится автоматически: раньше программа не заглядывала в `%APPDATA%\Mozilla\Firefox\Profiles`.
- Профили читаются и из `profiles.ini`, поэтому находятся и профили, созданные в другой папке.
- Самым свежим считается профиль, у которого недавно менялся `prefs.js`.
- Если параметр `toolkit.legacyUserProfileCustomizations.stylesheets` не задан, у Firefox он выключен по умолчанию. Теперь программа об этом предупреждает. Также учитывается `user.js`.
