# Менеджер контекстного меню (Context Menu Manager)

Программа для Windows 10/11, которая показывает **все** пункты контекстного меню Проводника
(правый клик по файлам, папкам, дискам, рабочему столу и т. д.) и позволяет безопасно их
отключать, включать, скрывать за Shift и добавлять свои пункты. Ничего системного не удаляется:
каждое изменение обратимо, записывается в журнал и сопровождается резервной копией `.reg`.

Интерфейс на русском и английском, светлая и тёмная тема (Fluent, как в Windows 11).

## Запуск

1. Распакуйте архив и запустите `ContextMenuManager.exe`.
   Это один самодостаточный файл: устанавливать .NET не нужно.
2. Программа запускается **без прав администратора**. Пункты текущего пользователя (HKCU)
   меняются сразу. Для пунктов «для всех пользователей» (HKLM) программа предложит
   перезапуститься от имени администратора (кнопка «Права администратора» в шапке).
3. Часть изменений видна только после перезапуска Проводника: кнопка «Перезапустить Проводник».

Требования: Windows 10 1809 (17763) или новее, x64.

> Windows SmartScreen может предупредить о неизвестном издателе, потому что exe не подписан.
> Нажмите «Подробнее» → «Выполнить в любом случае».

## Возможности

### Все пункты меню
* Сканирование реестра: команды `shell`, расширения оболочки `shellex\ContextMenuHandlers`,
  вложенные подменю (`shell`-подключи, `SubCommands` из CommandStore, `ExtendedSubCommandsKey`).
* Группировка по месту появления: рабочий стол, пустое место в папке, папки, диски, все файлы,
  изображения, видео, аудио, документы, архивы, программы, корзина, «Этот компьютер»,
  библиотеки, сеть, принтеры и др.
* Для каждого пункта видно: название, программа и издатель (из свойств DLL/EXE), команда,
  модуль, путь в реестре, сторонний это пункт или системный.
* Фильтры: поиск по названию/программе/команде/CLSID, «только сторонние», «только
  отключённые», «только Shift-пункты».
* **Фильтр по расширению**: введите `.mp4` — увидите всё меню, которое появится для такого файла
  (`*`, `AllFilesystemObjects`, ProgID, выбранная пользователем программа, `SystemFileAssociations`, PerceivedType).
* Массовые действия «Включить все» / «Отключить все» для показанного списка
  (критичные системные пункты пропускаются).

### Способы отключения (все обратимые)
* Команды (`shell`): значение `LegacyDisable`; альтернативно `ProgrammaticAccessOnly`
  («скрыть, оставив доступ программам»).
* Расширения оболочки: на выбор в настройках
  * переименование ключа в `-Имя` (по умолчанию, действует на один тип файлов);
  * блокировка CLSID в `Shell Extensions\Blocked` (убирает расширение отовсюду).
* «Только с Shift» (`Extended`) и позиция в меню (`Position` = Top/Bottom).
* Предупреждение перед отключением критичных пунктов («Открыть», «Создать», «Открыть с помощью»,
  «Отправить» и т. п.) — отключается в настройках.

### Живой предпросмотр

Отдельный режим, который рисует контекстное меню таким, каким его сейчас показывает Windows, и позволяет включать и отключать пункты прямо в нём.

- **Куда нажимаем:** пустое место на рабочем столе, пустое место в папке, папка, диск, файл, фото, видео, музыка, документ, архив, программа (.exe). Для файлов можно указать своё расширение, например `.png` или `.mkv`.
- **Вид меню:** новое меню Windows 11 или классическое («Показать дополнительные параметры», Windows 10). Нажатие на «Показать дополнительные параметры» в макете открывает классический вид. Если в разделе «Windows 11» включено классическое меню, доступен только классический вид.
- **Как собирается макет:** встроенные пункты Проводника («Вид», «Сортировка», «Обновить», «Вставить», «Создать», «Свойства» и т. д.) плюс все найденные пункты реестра, расширения оболочки и пункты пакетных приложений, которые относятся к выбранному объекту. Учитывается, что Проводник убирает дубликаты: пункт из более точного раздела и из HKCU побеждает. В новом меню Windows 11 видны только встроенные и пакетные пункты, остальные находятся в «Показать дополнительные параметры».
- Значки, разделители, подменю (нажмите на пункт со стрелкой, подменю откроется рядом), подменю «Создать» из вашего списка ShellNew.
- **Переключатели прямо в меню.** Встроенные пункты, за которые отвечает запись реестра (например, «Создать», «Отправить», «Параметры экрана»), тоже можно выключить. Все изменения идут через тот же механизм, что и в списке, попадают в журнал и отменяются.
- **Отключённые пункты** показаны серыми и зачёркнутыми с меткой «Откл.»; флажок «Показывать отключённые» их скрывает. Пункты, видимые только с Shift, помечены «Shift»; флажок «Как с зажатым Shift» показывает меню в расширенном виде. ПКМ по пункту: «Только с Shift», «Показать в списке».
- **Реальное меню Windows** (флажок): программа просит Windows построить настоящее классическое меню (IContextMenu) для примера файла или папки в `%TEMP%\CtxMenuPreview`, читает его тексты, значки и подменю и связывает строки с записями реестра, чтобы их можно было переключать. Ни одна команда при этом не выполняется. Если чтение не удалось, показывается макет из реестра.

### Меню «Создать»
* Список всех пунктов подменю «Создать» (`ShellNew`), включение/отключение (переименование
  в `-ShellNew`) со сбросом кэша Проводника.
* Добавление своих типов: `.md`, `.py`, `.json`… — пустой файл или копия файла-шаблона.
  Свои пункты можно удалить.

### WinRAR и 7-Zip
* Отдельные пункты меню архиваторов (Извлечь здесь, Добавить в архив, CRC SHA и т. д.)
  включаются и выключаются через настройки самих архиваторов
  (`HKCU\Software\WinRAR\Setup\MenuItems`, `HKCU\Software\7-Zip\Options\ContextMenu`),
  поэтому изменения переживают обновления. Также: вложенное меню и значки.

### Windows 11
* Переключатель **классического контекстного меню** (без «Показать дополнительные параметры»).
* Пункты MSIX/Store-приложений нового меню (Terminal, PowerToys, Notepad и др.) — читаются из
  `AppxManifest.xml` и отключаются блокировкой CLSID для текущего пользователя.

### Свои пункты и группы
* Своя команда: название, программа, аргументы (`%1`, `%V`, `%W`), значок, где показывать
  (рабочий стол, фон папки, папки, диски, все файлы, тип файла по расширению…),
  «только с Shift», позиция, «от имени администратора», «для всех пользователей».
* Группа — подменю с несколькими командами. Команды можно добавлять и в существующие
  подменю других программ (если они построены на `shell`-подключах).
* Созданные пункты помечаются и удаляются только программой; чужие ключи не удаляются никогда.

### Журнал, откат, профили
* Каждое действие — запись в журнале с описанием, списком операций и резервной копией `.reg`.
* Отмена любого изменения, отмена последнего (Ctrl+Shift+Z), «Вернуть всё».
* Экспорт выбранного пункта в `.reg`, открытие в regedit, копирование пути.
* Профили: сохранить в JSON отключённые, Shift-пункты и свои пункты и применить на другом ПК.

## Где хранятся данные

`%LOCALAPPDATA%\ContextMenuManager\`
* `journal.json` — журнал изменений;
* `Backups\*.reg` — резервные копии перед каждым изменением (можно импортировать двойным щелчком);
* `settings.json` — настройки; `custom-entries.json` — свои пункты; `Templates\` — шаблоны «Создать»;
* `error.log` — ошибки, если что-то пошло не так.

## Горячие клавиши

* `F5` — пересканировать реестр;
* `Ctrl+Shift+Z` — отменить последнее изменение.

## Сборка из исходников

Нужен .NET SDK 10.

```powershell
dotnet test tests/CtxMenu.Core.Tests
dotnet publish src/CtxMenu.App/CtxMenu.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Структура:
* `src/CtxMenu.Core` — логика (net8.0, без зависимостей от Windows): сканер реестра, редактор
  с транзакциями и откатом, журнал, сервисы («Создать», архиваторы, Windows 11, свои пункты,
  профили), локализация. Работает через интерфейс `IRegistry`, поэтому полностью тестируется
  на реестре в памяти.
* `src/CtxMenu.App` — WPF-приложение (net10.0-windows, Fluent-тема, MVVM).
* `tests/CtxMenu.Core.Tests` — модульные тесты xUnit.
